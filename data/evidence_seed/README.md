# Evidence seed boundary

`claims.json` contains a deliberately small set of source-checked claims. The catalog manifest is
`secondary_ai_verified`, not `production_approved`; owner/domain-expert review is still required
before these claims can authorize operational thresholds or dose rules.

The records preserve source identifiers, uncertainty, limitations, applicability, reviewer state,
and claim version. They are not permission to infer unrecorded findings from the cited papers.
